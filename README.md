# InternShield 🛡️
**Check Before You Apply** | *VinHack 2026 Submission*

InternShield is a mobile risk-assessment application that helps students analyze potentially fraudulent internship and job opportunities before they share sensitive data or pay registration fees. 

## Features
* **Rule-Based Engine:** Analyzes job descriptions for predatory language and common scam indicators.
* **Explainable Risk Scoring:** Generates a 0-100 risk score and categorizes opportunities as LOW, MEDIUM, or HIGH risk.
* **Red Flag Detection:** Explicitly highlights suspicious requests (e.g., "OTP required", "Registration fee").

## Tech Stack
* **Frontend:** Flutter & Dart
* **Backend:** Python & FastAPI
* **Detection:** Custom Python Heuristic Algorithm
